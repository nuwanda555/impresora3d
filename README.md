# impresora3d

Simulador didáctico de impresión 3D FDM, con laminado, cinemática cartesiana, CoreXY y delta, diagnóstico de defectos, retos y evaluación.

**Abrir la web:** https://nuwanda555.github.io/impresora3d/

Publicado con GitHub Pages desde la rama `main`. El simulador está en `index.html` y las librerías y estilos locales en `assets/`.

Los archivos STL, OBJ y G-code se procesan en el navegador. Las preferencias se guardan localmente en cada navegador.
